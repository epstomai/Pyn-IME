Pyn 拼音输入法 (Windows 10/11, 64 位系统)

安装：双击 install.cmd，按提示允许管理员权限。
      完成后按 Win+空格 切换到 Pyn。已打开的程序如未出现 Pyn，重启该程序即可。
设置：开始菜单 -> Pyn 设置。
卸载：双击 uninstall.cmd。用户词库与设置保留在 %LOCALAPPDATA%\Pyn。

文件说明：
  ime_tsf.dll / ime_tsf_x86.dll  输入法文本服务 (64 位 / 32 位程序)
  ime-server.exe                 后台服务，全系统共享一份模型与用户词库
  ime-settings.exe               设置程序
  models\                        语言模型与神经网络重排模型
